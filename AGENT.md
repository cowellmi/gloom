This is an embedded project for the Feather M0 with SAMD21 microprocessor.

The Hypnos is a custom PCB board in FeatherWing form. It stacks on top of the Feather M0. The Hypnos board has 2 MOSFETs, a DS3231 RTC, and an SD card reader. It is intended to connect sensors to power rails on Hypnos and use Hypnos to power on/off the sensors when entering STANDBY mode on the Feather M0. The DS3231 provides to 2 alarms which can be used to wake the Feather M0 from standby mode.
